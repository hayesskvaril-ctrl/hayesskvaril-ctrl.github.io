# Template builders

Downloadable templates in `/assets/templates/` are generated by these scripts, so they can be
rebuilt consistently after edits.

```
python3 _scripts/templates/build_risk_assessment.py
python3 _scripts/templates/build_breach_register.py
node    _scripts/templates/build_incident_report.js
```

After building a spreadsheet, recalculate it with LibreOffice so formula results are cached
(otherwise some previewers show blank cells). Needs `libreoffice-calc` installed:

```
soffice --headless --convert-to xlsx --outdir /tmp/recalc assets/templates/<file>.xlsx
cp /tmp/recalc/<file>.xlsx assets/templates/
```

Check for formula errors after recalculating, and open the file to confirm the example row
calculates as expected.
