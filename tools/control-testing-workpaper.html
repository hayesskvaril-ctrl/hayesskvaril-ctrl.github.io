Control testing workpaper

A workpaper for testing one control from start to finish: what the control is meant to do, whether it is well designed, what you tested, what you found and what you concluded.

Intermediate Excel spreadsheet Last reviewed: 28 September 2026
Download the template (.xlsx)

Excel workbook, about 23 KB. Works in Excel, Google Sheets and LibreOffice. Free to use and adapt.

Key takeaways

  • Test design first (would the control work if performed as described?), then operating effectiveness (did it actually work, consistently, over the period?).
  • Define the population and check it is complete before you sample. A perfect sample from an incomplete population proves little.
  • Test specific attributes, so an exception is clear and objective.
  • The upper deviation limit shows how bad the control could really be, given what the sample found. One exception in 25 can still mean a meaningful failure rate.

The worked example

The template comes filled in with a fictional test of a four-eyes approval over super benefit payments. Twenty-five payments were tested and one was released before approval during a system outage. The results show why a single exception matters:

Example results (95% confidence, 10% tolerable exception rate)
MeasureResult
Items tested25
Exceptions1 (4.0% of the sample)
Upper deviation limit17.6%
Statistical resultDoes not support reliance: the upper limit is above the 10% tolerable rate
Conclusion recordedPartially effective, with an action to review every system override

The sample exception rate is only 4%, but with 25 items you can only be 95% confident that the true rate is below about 17.6%. See control testing and sampling for how this works, and try the interactive calculator there.

A starting point, not a finished framework

Sample sizes, tolerable rates and rating scales should come from your own testing methodology. The statistical check assumes a random sample from a large population. Judgement still matters: an exception caused by fraud or a design flaw can matter more than the rate suggests.
