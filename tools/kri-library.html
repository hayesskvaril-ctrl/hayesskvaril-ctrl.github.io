Key takeaways

  • A KRI is a measure that signals a change in risk, ideally before harm occurs.
  • Thresholds should link to risk appetite: amber is an early warning, red means outside appetite and triggers escalation.
  • Balance leading indicators (what might happen) with lagging ones (what has happened).
  • All thresholds in the library are illustrative, not benchmarks.

To see indicators like these in action, try the KRI dashboard demo on the risk appetite and tolerance page.

A starting point, not a finished framework

A KRI is only useful if it measures the risk described in your appetite statement and actually moves before problems occur. Review the library against past incidents and replace indicators that stayed green while things went wrong.
