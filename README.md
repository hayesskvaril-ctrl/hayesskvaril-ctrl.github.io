# Regulator watch data

This branch is written by the weekly regulator watch (`.github/workflows/regulator-watch.yml` on the main branch).
It is not part of the published website.

- `seen.json`: announcements already seen, per source
- `auto_checks.json`: whether each key fact was found on its official source page at the last run
- `latest_report.md`: the latest weekly report (also posted as a GitHub issue when there is something new)

See `_scripts/UPDATES.md` on the main branch.
