ASD Essential Eight

The Australian Signals Directorate's baseline set of cyber security mitigation strategies, and the maturity model used to measure them.

Intermediate About 8 minutes Last reviewed: 27 September 2026
Publisher
Australian Signals Directorate (ASD), through its Australian Cyber Security Centre
Current version
Essential Eight Maturity Model, last substantially updated November 2023.
Status
Mandatory for non-corporate Commonwealth entities under the Protective Security Policy Framework (to Maturity Level Two). Voluntary, but widely used as a benchmark, for other organisations.

Key takeaways

  • The Essential Eight are eight mitigation strategies that make it much harder for attackers to compromise systems: application control, patching applications, Microsoft Office macro settings, user application hardening, restricting administrative privileges, patching operating systems, multi-factor authentication and regular backups.
  • Each strategy is assessed against maturity levels from Zero to Three, based on the sophistication of attackers the controls can withstand.
  • Organisations should aim for the same maturity level across all eight strategies before moving higher, because attackers target the weakest point.
  • Non-corporate Commonwealth entities must implement Maturity Level Two. Many financial institutions use it as a benchmark alongside CPS 234.

The maturity levels

LevelWhat it protects against (summarised)
Maturity Level ZeroWeaknesses exist that would let attackers readily compromise systems.
Maturity Level OneOpportunistic attackers using widely available tools and techniques.
Maturity Level TwoAttackers willing to invest more time and effort, using more capable tools.
Maturity Level ThreeMore adaptive, targeted attackers who are persistent and exploit weaknesses in security.

The eight strategies, in plain English, are set out on the Cyber risk management page.

Using the Essential Eight well

  • Choose a target level based on the threats the organisation faces and its risk appetite.
  • Implement evenly. ASD recommends reaching a level across all eight strategies before moving to the next.
  • Assess properly. ASD publishes an assessment process guide; assessments should test that controls work, not just that they exist.
  • Remember it's a baseline. The Essential Eight focuses on common attack techniques on Windows-based networks. It doesn't cover everything, such as cloud services, third parties, detection or incident response.
  • Track progress. Commonwealth reporting shows reaching Maturity Level Two across all strategies is hard: in 2025 only a minority of entities had done so, with legacy systems a common barrier.
